What is CONTRIBO?

CONTRIBO revolutionizes how contributions are valued in the digital economy. Using advanced graph algorithms inspired by Potts' Contribution Theory, we create a fair, transparent system where your work's true impact determines its value.

How CONTRIBO Works

A step-by-step breakdown of our contribution valuation system

1. Project Setup

Projects define their contribution framework:

  • Set milestone-based goals with clear acceptance criteria
  • Define skill requirements and contribution types
  • Establish validation processes and reviewers

2. Contribution Tracking

All work is tied to verifiable outcomes:

  • Code contributions linked to merged PRs
  • Milestone completions validated by project maintainers
  • Reviews and audits with provable impact

3. Value Calculation

The CONTRIBO algorithm considers:

  • Dependency relationships between contributions
  • Project-defined weights for different work types
  • Time-based depreciation and maintenance value

4. Reputation & Rewards

Contributors earn portable value:

  • CONTRIBO Points (Cred) that transfer between projects
  • Skill attestations verified through actual work
  • Achievement badges for significant contributions
