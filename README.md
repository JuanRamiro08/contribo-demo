## About CONTRIBO

CONTRIBO is a Web3 platform connecting skilled contributors with innovative projects, rewarding impact through a transparent, graph-based reputation system.

### Key Features

- **Fair Contribution Valuation** - Rewards based on actual impact, not just time
- **Portable Reputation** - Build verifiable, on-chain reputation across projects
- **Milestone-Based Development** - Clear, achievable goals with defined acceptance criteria
- **Transparent Algorithms** - Understandable value calculations you can trust
